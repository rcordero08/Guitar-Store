# Proyecto - Guitar Store

Aplicación web desarrollada con **React**, **TypeScript** y **Vite**, enfocada en ofrecer un rendimiento óptimo y un código mantenible.

## 🚀 Tecnologías utilizadas
- **React**: Construcción de interfaces modulares y reutilizables.
- **TypeScript**: Tipado estático para mayor robustez y detección temprana de errores.
- **Vite**: Entorno de desarrollo rápido y optimizado para producción.
- **React Hooks**: Manejo de estado y ciclos de vida (`useState`, `useEffect`, `useMemo`)

## 📌 Características principales
- Código basado en buenas prácticas (**Clean Code** y principios **SOLID**).
- Arquitectura orientada a componentes y reutilización.
- Aplicación ligera y de alta performance.
